## Инструкция для Qwen: как собрать сайт-базу знаний на Nuxt

---

## ЧТО ЭТО И ЗАЧЕМ

Это структурный план базы знаний сайта **Артема Селифанова** — интернет-маркетолога, блогера и no-code разработчика.

Исходник: экспорт Telegram-канала «Нескучный Нетворкинг» (286 постов, июль 2025 — март 2026).
После фильтрации: **223 полезных материала**, разбитых по **9 темам**.

**Главная идея**: не архив постов в хронологии, а **база знаний с маршрутами обучения**.
Читатель приходит с вопросом → выбирает тему → читает посты по логичному порядку → получает ответ.

## СТРУКТУРА ГЛАВНОЙ СТРАНИЦЫ `/knowledge`

1. **Шапка**
   - Заголовок: «База знаний Нескучного Нетворкинга»
   - Подзаголовок: «220+ постов → структурированные маршруты обучения. Найди ответ на свой вопрос.»
   - Автор: Артем Селифанов — интернет-маркетолог · блогер · no-code разработчик

2. **Статистика** (3 числа в ряд):
   - 220+ материалов | 9 тем | Пополняется регулярно

3. **Облако тем** — карточки, кликабельные, ведут на страницу темы.
   Порядок по убыванию количества материалов:
   - ✍️ Контент-стратегия — 42 материала → `/knowledge/content-strategy`
   - 🌐 Платформы и алгоритмы — 38 материалов → `/knowledge/platforms`

   - 🎬 Реалити-проекты — 22 материала → `/knowledge/reality-projects`
   - 🧬 История автора — 18 материалов → `/knowledge/author-story`
   - 🤖 Инструменты и ИИ — 16 материалов → `/knowledge/tools-ai`

4. **Блок «Как пользоваться»**:
   1. Выбери тему в облаке
   2. Читай посты по порядку — от простого к сложному
   3. Один пост может быть в нескольких темах

## СТРУКТУРА СТРАНИЦЫ ТЕМЫ `/knowledge/[slug]`

1. Хлебные крошки: База знаний → [Название темы]
2. Заголовок + иконка + описание темы
3. Счётчик: N материалов
4. Список материалов — пронумерованные карточки постов в заданном порядке.
   Каждая карточка:
   - Номер в маршруте
   - Заголовок поста (первая строка text)
   - Дата публикации
   - Теги смежных тем (если пост в нескольких темах)
   - Кнопка «Читать» → `/knowledge/post/[id]`
5. Навигация: ← предыдущая тема | следующая тема →

---

## СТРУКТУРА СТРАНИЦЫ ПОСТА `/knowledge/post/[id]`

1. Хлебные крошки: База знаний → [Тема] → [Заголовок]
2. Дата публикации
3. Теги тем (пост может быть в 1–3 темах)
4. Полный текст поста (из поля `text` в JSON)
5. Навигация: ← предыдущий в теме | следующий в теме →
6. Блок «Читай также» — посты из смежных тем

---

## КАК ЧИТАТЬ ЭТОТ ФАЙЛ

- `post_id` = поле `id` из исходного `result.json`
- Полный текст поста = `messages[].text` где `messages[].id == post_id`
- Порядок постов в каждой теме = порядок чтения (логика обучения, не хронология)
- Посты с несколькими тегами → появляются в каждой теме
