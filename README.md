# YAPPIE Website

> **AI Agent Documentation:** See `.ai/` folder

Development of websites, web applications, and chatbots for business.

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run generate
```

## Deploy

Auto-deploys to GitHub Pages on push to `main`.

```bash
git add .
git commit -m "Update"
git push origin main
```
