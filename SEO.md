## 🔍 Рекомендации по SEO

1. **Title**: Все основные страницы имеют уникальные title с указанием бренда
2. **Description**: Описания содержат ключевые слова и призыв к действию
3. **H1**: Заголовки соответствуют содержанию страниц
4. **Keywords**: Добавлены ключевые слова для основных страниц
5. **Open Graph**: Настроены мета-теги для социальных сетей
6. **Twitter Card**: Настроены мета-теги для Twitter
7. **Schema.org**: Добавлена микроразметка для организаций и персоны
