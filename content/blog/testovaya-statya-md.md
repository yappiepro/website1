# Введение в Markdown для блога

Это пример статьи, написанной в формате **Markdown**. Теперь вы можете писать статьи удобно и быстро, без необходимости оборачивать текст в HTML теги.

## Преимущества Markdown

1. **Простота** — пишете текст как в обычном редакторе
2. **Читаемость** — файл выглядит понятно даже в сыром виде
3. **Подсветка кода** — блоки кода автоматически подсвечиваются
4. **Автоматическое оглавление** — генерируется из заголовков

## Пример кода

Вот как выглядит блок кода с подсветкой синтаксиса:

```javascript
// Пример функции на JavaScript
function greet(name) {
  return `Привет, ${name}!`
}

console.log(greet('Мир'))
```

## Списки и цитаты

### Маркированный список

- Первый элемент
- Второй элемент
- Третий элемент

### Нумерованный список

1. Шаг первый
2. Шаг второй
3. Шаг третий

> Это пример цитаты. Можно использовать для выделения важных мыслей или цитирования источников.

## Заключение

Теперь вы можете писать статьи в удобном формате Markdown, а старые статьи остаются в JS файлах. Гибридный подход позволяет постепенно переходить на новый формат без потери существующего контента.
