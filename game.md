# 📋 Техническое задание для AI-агента кодера

## 🎯 Общая концепция проекта

Создать веб-приложение на **Nuxt 3** с интерактивными обучающими карточками в формате stories/reels. Каждая карточка листается вертикально (свайп вверх/вниз или скролл колесом мыши). 

**Ключевой принцип архитектуры:** 
- Сначала идёт **обучающий блок** (статичный контент с теорией)
- Затем идёт **интерактивный блок** (тест/игра для проверки знаний)
- Результаты каждого теста сохраняются и суммируются в финальной карточке

---

## 🎨 Дизайн-система

### Цвета:
- **Основной фон:** `#0a0a0a` до `#1a1a1a` (градиент)
- **Акцентный лайм:** `#c8f060` (используется для заголовков, кнопок, правильных ответов)
- **Вторичный оранжевый:** `#ff6b35` (для тёплых состояний, акцентов)
- **Вторичный фиолетовый:** `#a78bfa` (для холодных состояний, акцентов)
- **Зелёный (успех):** `#4ade80`
- **Красный (ошибка):** `#ef4444`
- **Белый текст:** `#ffffff`
- **Серый текст:** `rgba(255, 255, 255, 0.7)`

### Типографика:
```
Заголовки H1, H2: 
- Font-family: 'Unbounded', sans-serif (жирный, 700-900)
- Использовать для: заголовки карточек, крупные цифры, формулы

Основной текст:
- Font-family: 'Golos Text', sans-serif (400-600)
- Использовать для: описания, вопросы, кнопки, пояснения
```

### Радиусы скругления:
- Карточки: `20px`
- Кнопки: `12px`
- Элементы форм: `8px`

### Тени и эффекты:
- Неон-эффект для лайма: `box-shadow: 0 0 40px rgba(200, 240, 96, 0.3)`
- Карточки: `box-shadow: 0 4px 24px rgba(0, 0, 0, 0.5)`
- Hover на кнопках: приподнимается на 2px, тень усиливается

## 📱 Структура карточек (всего 8 слайдов)

### **КАРТОЧКА 1: Вводный крючок (статичная)**

**Цель:** Привлечь внимание и заинтересовать пользователя

**Контент:**
```
┌────────────────────────────────────┐
│                                    │
│         [Иконка вопроса]           │ ← Пульсирующий круг с "?"
│            120x120px               │
│                                    │
│    А ты точно знаешь свою ЦА?      │ ← H1, 42px, градиент
│                                    │
│      Или просто угадываешь?        │ ← subtitle, 20px
│                                    │
│          Свайпни вверх ↑           │ ← hint, анимация bounce
│                                    │
└────────────────────────────────────┘
```

**Анимации:**
- Иконка вопроса: пульсация (scale 1.0 → 1.05) каждые 2 секунды
- Hint внизу: bounce анимация вверх-вниз
- При появлении карточки: fade-in 0.5s

**Технические детали:**
- Вся карточка центрирована по вертикали и горизонтали
- Иконка в круге с лаймовой обводкой `border: 2px solid #c8f060`
- Фон круга: `rgba(200, 240, 96, 0.1)`

   - Каждая карточка: `scroll-snap-align: start`
   - Smooth scrolling

   - Когда пользователь проходит тест/игру, блокировать переход к следующей карточке
   - Разблокировать только после завершения (появления кнопки "Дальше")

### **Touch обработка (мобильные):**

```javascript
let touchStartY = 0
let touchEndY = 0

const handleTouchStart = (e) => {
  touchStartY = e.touches[0].clientY
}

const handleTouchMove = (e) => {
  touchEndY = e.touches[0].clientY
}

const handleTouchEnd = () => {
  const swipeDistance = touchStartY - touchEndY
  const threshold = 50 // минимум 50px для свайпа
  
  if (Math.abs(swipeDistance) > threshold) {
    if (swipeDistance > 0) {
      goToNextSlide()
    } else {
      goToPreviousSlide()
    }
  }
}
```

### **Хранение данных:**

```javascript
// Использовать localStorage для сохранения прогресса
const saveProgress = () => {
  const progress = {
    quizScore,
    temperatureScore,
    channelsScore: goodChannelsCount,
    mistakesScore,
    currentSlide,
    timestamp: Date.now()
  }
  
  localStorage.setItem('ca_learning_progress', JSON.stringify(progress))
}

// Восстановление при возврате
const loadProgress = () => {
  const saved = localStorage.getItem('ca_learning_progress')
  if (saved) {
    const progress = JSON.parse(saved)
    
    // Проверка: если прошло меньше 24 часов
    const hoursPassed = (Date.now() - progress.timestamp) / (1000 * 60 * 60)
    if (hoursPassed < 24) {
      return progress
    }
  }
  return null
}
```
